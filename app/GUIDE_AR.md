# دليل واجهة CorroVision

واجهة Streamlit بالعربي والإنجليزي: ترفع صورة هيكل بحري، فتعرض هل هو سليم أو متآكل، ونوع التآكل، وخريطة
حرارية (Grad-CAM) تبيّن أين ركّز النموذج.

## 1. التشغيل على جهازك

تحتاج Python 3.10 أو أحدث.

```bash
git clone https://github.com/deem-de/CorroVision.git
```

```bash
cd CorroVision
```

```bash
pip install -r app/requirements.txt
```

```bash
streamlit run app/app.py
```

يفتح المتصفح تلقائياً على `http://localhost:8501`. أول تشغيل ينزّل أوزان ResNet50 (نحو 95MB) ويأخذ دقيقة.
لإيقاف التطبيق اضغط `Ctrl + C` في نافذة الأوامر.

لا تحتاج تنزيل أي ملفات نموذج إضافية: رأسا التصنيف موجودان في `app/models/` (نحو 6MB لكل واحد).

## 2. الصفحات

**تحليل صورة**

1. ارفع صورة، أو فعّل "استخدم الكاميرا" والتقط صورة.
2. "خطوات المعالجة المسبقة" تعرض الصورة بعد كل خطوة من الأربع: تغيير الحجم، إزالة التشويش، تصحيح
   الألوان، وCLAHE. هي نفس خطوات التدريب.
3. المرحلة 1: بطاقة خضراء (سليم) أو حمراء (تآكل)، وعدّاد لاحتمالية التآكل. الخط الأسود على العدّاد هو حد القرار.
4. المرحلة 2: تظهر فقط إذا كانت الصورة متآكلة. تعرض النوع، شرحاً قصيراً، إجراءً مقترحاً، وأعلى 3 احتمالات.
5. Grad-CAM: الأحمر يعني المناطق الأكثر تأثيراً في القرار.
6. زر تحميل النتيجة كملف JSON.

**نتائج المشروع**: أرقام مجموعة الاختبار من مجلد `results/`: بطاقات الدقة، مقارنة الطرق السبع مع فترات
الثقة، الـRecall لكل نوع تآكل، أشكال التقرير، والجداول كاملة.

**عن المشروع**: المشكلة، فكرة المرحلتين، البيانات، والحدود.

## 3. الشريط الجانبي

- **اللغة**: عربي أو إنجليزي. الصورة المرفوعة تبقى عند التبديل.
- **حد قرار التآكل**: الافتراضي 0.50، وهو المستخدم في نتائج التقرير. رفعه يجعل النموذج يحتاج ثقة أعلى ليقول "متآكل".
- **التحسين وقت الاختبار (TTA)**: يقيّم الصورة ونسختيها المقلوبتين ويأخذ المتوسط. أبطأ قليلاً.
- **Grad-CAM**: إظهار أو إخفاء الخريطة الحرارية.

## 4. النموذج المستخدم

ResNet50 مدرّب على ImageNet ومجمّد، وفوقه رأسا تصنيف دُرّبا في هذا المشروع (المرحلة 1 والمرحلة 2).
دقته على مجموعة الاختبار: 99.56% للمرحلة 1، 74.06% للمرحلة 2، و76.58% للتسع فئات معاً.

لماذا ليس نموذج الدمج (77.84%)؟ الفرق بينهما غير دال إحصائياً في اختبار McNemar (p = 0.61)، وResNet50
المجمّد نموذج واحد صغير يمكن وضعه في الريبو. النماذج بعد الـfine-tuning حجمها 190MB للواحد، وهو أكبر من حد
GitHub (100MB).

## 5. الملفات

| الملف | وظيفته |
| --- | --- |
| `app.py` | الواجهة: الصفحات، الرسوم، الألوان |
| `predictor.py` | تحميل النموذج، المعالجة المسبقة، التنبؤ، وGrad-CAM |
| `texts.py` | كل النصوص بالعربي والإنجليزي، وشرح أنواع التآكل الثمانية |
| `models/` | رأسا التصنيف وأسماء الفئات |
| `requirements.txt` | المكتبات المطلوبة |

## 6. التعديل

- **الألوان**: في أعلى `app.py` المتغيرات `TEAL` و`NAVY` و`RED` و`GREEN`.
- **النصوص**: في `texts.py`، القاموس `T` فيه نسخة `en` ونسخة `ar` لكل نص.
- **شرح نوع تآكل أو الإجراء المقترح**: في `texts.py`، القاموس `TYPES`.
- **إضافة لغة**: أضف مفتاحاً جديداً في `T` و`TYPES` وأضفه لخيارات اللغة في `app.py`.

## 7. النشر أونلاين مجاناً (Streamlit Community Cloud)

1. افتح [share.streamlit.io](https://share.streamlit.io) وسجّل الدخول بحساب GitHub.
2. اضغط **Create app** ثم **Deploy a public app from GitHub**.
3. اختر الريبو `deem-de/CorroVision`، الفرع `main`، والملف `app/app.py`.
4. اضغط **Deploy** وانتظر عدة دقائق.

تحصل على رابط ثابت ترسله لأي أحد. الخطة المجانية ذاكرتها محدودة (نحو 1GB)، وTensorFlow مع ResNet50 قريب من
هذا الحد، فإذا توقف التطبيق بسبب الذاكرة شغّله من جهازك وقت العرض.

## 8. مشاكل شائعة

- **`streamlit: command not found`**: استخدم `python -m streamlit run app/app.py`.
- **`FileNotFoundError` لملف في `results/`**: شغّل الأمر من مجلد الريبو الرئيسي، وليس من داخل `app/`.
- **أول صورة بطيئة**: تحميل النموذج يأخذ نحو 20 ثانية مرة واحدة، وبعدها كل صورة تأخذ ثانية أو ثانيتين.
- **الكاميرا لا تعمل**: المتصفح يسمح بالكاميرا فقط على `localhost` أو رابط `https`.

## 9. نصائح للعرض

- جهّز 3 صور مسبقاً: سليمة، متآكلة واضحة، وواحدة يتردد فيها النموذج بين نوعين.
- اعرض Grad-CAM واشرح أنه يبيّن أين نظر النموذج، وأنه مؤشر تقريبي وليس تحديداً دقيقاً لمكان الضرر.
- حرّك حد القرار أمام الحضور لتبيّن كيف يتغير الحكم، واربطه بمشكلة عدم توازن الفئات في المرحلة 1.
- اذكر الحدود بصراحة: المرحلة 2 تصيب نحو 3 مرات من 4، والداتا ليست كلها صوراً حقيقية تحت الماء.
